# 一车菜

## 项目

- 片名：一车菜
- 时代 / 地点：1996 年盛夏，鲁西南农村与镇上早市
- 篇幅：3 场 / 20 镜 / 2 分 26 秒
- 画风：2D 动画（赛璐璐上色、干净线稿、手绘背景）
- 主镜头时长：10 秒 ×3、8 秒 ×11、5 秒 ×6

## 世界设定

视觉语言：2D anime, cel-shaded, clean line art, limited palette, hand-drawn background.

- 配色限定：土黄、褪色粉、军绿、靛蓝、灰白；全片不加高饱和色
- 线条：深褐线稿，线宽统一；阴影只做两档平涂，不做渐变
- 光：清晨低角度暖光（3200K）与早市斜射光（3500K），包子铺棚下散射（3600K）
- 禁止：3D 渲染感、厚涂、写实皮肤、真实景深虚化、现代物件、文字招牌
