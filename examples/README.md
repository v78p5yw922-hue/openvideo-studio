# 示例

## `hijack_8.md`

8 镜 / 40 秒的完整剧本，可直接导入：顶部「导入剧本」→ 粘贴内容 → 项目 ID 填 `demo`。

导入后还需要两步才有画面：

1. **角色参考图**：叶谦（3 张最稳）、劫匪首领、西装中年人（各 1–2 张）
2. **场景母版**：一张空的头等舱图（无人的机舱），作为 `锚定=plate` 的首帧

## `sample-720p.mp4`

这 8 镜实际渲出来的成片（1280×720，压缩版，原片 1344×768 / 41.4 秒 / 22 MB）。

- 意图：证明整条链路真的能出片，而不是只跑通接口
- **注意**：这是"能讲清故事"的水平，不是"能卖"的水平；角色一致性、动作幅度都还是有明显缺陷
