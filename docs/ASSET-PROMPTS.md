## 三、生成与上传流程

```
1. 千问生成 → 每张单独保存
2. 角色图：
   打开 :8801 → 左侧角色卡 → 上传参考图（第 1 张是主参考）
   三个视角都传，顺序：正面 → 3/4 → 侧面
3. 场景图：
   场景卡 → 上传第一张为母版
   其余点「追加视角」→ POST /api/projects/{pid}/scenes/{sid}/plates
4. 回到顶部就绪条：
   DESC_CONFLICT / REF_TOO_FEW 消失 = 图与文字一致了
5. 再渲一镜验证：发型应在所有镜头里一致
```
