# 剧本格式 v3（给编剧 / DeepSeek 用）

> 这份文档可以直接整段贴给 DeepSeek 网页版。
> 目标：**用固定的词表描述画面**，不要用自由散文去"暗示"构图。
> 你只能从下面的词表里选值；选错值会被校验器拦下并列出允许值。

---

## 0. 一句话原则

**空间关系用字段，不用形容词。**

- ❌ 不要写：`两人面对面站着，气氛紧张`
- ✅ 要写：`【关系】面对面` + 每个人物的 `朝向` `视线` `对象`

因为视频模型只能稳定执行**结构化空间描述**，无法从散文里可靠推断"谁看着谁"。

## 每镜 prompt 的三个新槽（写完必须自查）

在原有 `【机位】【人物】【关系】【语气】【开口】【节奏】【场景】【画质】` 之外，
**按需**加这三个槽。它们的共同目的：让模型不用猜"东西是什么状态、手空不空、这一镜接着上一镜吗"。

### 【接续】—— 这一镜和上一镜什么关系

```
【接续】无            硬切（默认，绝大多数镜头）
【接续】接上一帧       第 0 帧 = 上一镜末帧（只有"同一个动作延续"时用）
【接续】姿势承接       不钉帧，靠文字承接（写清上一镜结尾的姿势/手位/视线）
【接续】动作中段       切在动作中途，下一镜从同一动作的中段开始
```

**选"接上一帧"必须同时满足**：上一镜末帧可用、机位高度差 ≤ 一档、本镜首拍是**延续动作**。
不满足就别选——实测选了会让模型保持上一镜姿势，本镜动作不再发生。

### 【服装状态】—— 单镜的穿着/鞋/脏净

整集造型写在角色卡或「本剧覆盖」里；**单镜变化**写这里：

```
【服装状态】小石头：赤脚（凉鞋摆在炕沿下）
【服装状态】妈妈：蓝套袖卷到肘上、袖口是湿的
```

注意：角色卡里不要写死"始终穿鞋"，否则会出现"穿着凉鞋睡觉"这种画面。

### 【道具卡】—— 出现在这一镜的关键道具

```
【道具卡】油纸包（猪脸肉）：卤好的熟食、酱红油亮、切成薄薄的小片、
         暗黄油纸四角对折、没有绳子、油渗出一点；去向=递给小石头后仍在桌上
```

**四要素**：状态（生/熟、整/切）· 外观（颜色/材质/有无绳子）· 尺寸 · 去向。
道具一旦出现，必须在节奏里交代它最后在哪，否则模型会把它抹掉。

### 三个槽与词库的关系

写这些槽时，词从 `studio/data/script-glossary.json` 里选（动作 / 道具状态 / 视线 / 光 / 接续 / 声音），
校验器也用同一份词库判"该写的词有没有写"。**换剧情只改词库，不改代码。**

## 每镜 prompt
```

前四段和以前一样（见 `SCRIPT-FORMAT.md`），**变化在【镜头表】和【每镜 prompt】的空间字段**。

## 2. 镜头表（每行一镜）

表头固定十列：

```
| 镜号 | 场景 | 出场角色 | 机位 | 动作 | 台词 | 音效 | 配乐 | 转场 | 锚定 |
```

| 列 | 取值 |
|---|---|
| 镜号 | `镜 N（Xs）`，X 只能取 **5 / 8 / 10 / 15**（H3 原生档位；15 s = 362 帧） |
| 场景 | 场景卡里的 id |
| 出场角色 | 1–3 人，用 `、` 分隔 |
| 机位 | **见 3.1 词表**，格式：`景别+高度+角度+运镜，距离N米` |
| 动作 | 一句话，一个动作 |
| 台词 | `<d>说话人：台词</d>`；对某人说写 `<d>说话人→对象：台词</d>` |
| 音效 | 两层：环境底噪 + 动作声 |
| 配乐 | 只写器乐/速度/节奏，**不许写情绪词** |
| 转场 | `cut` 或 `chain` |
| 锚定 | `plate` 或空（只有空镜能用 plate） |

## 3. 词表（只能从这些值里选）

### 3.1 机位

| 字段 | 允许值 | 含义（模型侧英文） |
|---|---|---|
| **景别** | 大特写 / 特写 / 近景 / 中景 / 中全 / 全景 / 远景 | extreme close-up / close-up / medium close-up / medium shot / medium-full / full shot / wide shot |
| **高度** | 平视 / 略俯 / 俯拍 / 略仰 / 仰拍 | eye level / slightly high / high angle / slightly low / low angle |
| **角度** | 正面 / 过肩-左 / 过肩-右 / 侧对-左 / 侧对-右 / 背拍-左后 / 背拍-右后 / 反打 | frontal / over the left shoulder / ... / from behind, over the left shoulder / reverse angle |
| **运镜** | 固定 / 缓推 / 缓拉 / 横移 / 跟拍 / 手持 | static / slow push-in / slow pull-out / lateral track / follow / handheld |
| **距离** | 数字，单位米（0.4–8） | `{n} meters from the subject` |

> **角度必须带方位**（`-左` / `-右`）。不写方位时，人物在画面里的朝向会随镜头翻转——上一镜朝右、这一镜朝左，就是"越轴"，观众会以为他掉头了。
> 不带方位的旧写法（`过肩` / `侧对` / `背拍`）仍能用，但校验器会提示你补上。

### 3.1.1 时长只有三个档位

H3 的帧数只能是 `17k+5`，24fps 下能精确对齐的只有：

| 写的时长 | 实际帧数 | 实际秒数 |
|---|---|---|
| **5 秒** | 124 帧 | 5.17 |
| **8 秒** | 192 帧 | 8.00 |
| **10 秒** | 243 帧 | 10.13 |

写 6 秒、7 秒、9 秒都会被就近吸附（7 秒 → 192 帧 → 实际 8 秒），**净是白写**。校验器会提示 `DURATION_NOT_CANONICAL`。

写法：`景别=中景；高度=平视；角度=过肩；运镜=缓推；距离=1.5`

### 3.2 人物（每个角色一行）

| 字段 | 允许值 | 含义（模型侧英文） |
|---|---|---|
| **位置** | 左 / 中 / 右 / 左前 / 右前 | left of frame / center / right of frame / front-left / front-right |
| **层级** | 前景 / 中景 / 后景 | foreground / midground / background |
| **朝向** | 面向镜头 / 背对镜头 / 左3-4侧 / 右3-4侧 / 纯左侧 / 纯右侧 / 仰视镜头 | facing the camera / back to camera / three-quarter left / three-quarter right / profile left / profile right / looking up at camera |
| **视线** | 看对方 / 看镜头 / 看画外 / 闭眼 / 看手中物 | looking at {对象} / at the camera / off-screen / eyes closed / down at what they hold |
| **对象** | 角色名（当视线=看对方时**必填**，且必须在本镜出场角色里） | — |
| **占比** | 20–80 的整数，占画幅高度百分比 | `occupies {n}% of frame height` |

写法（一个角色一行，以 `- ` 开头）：

```
【人物】
- 叶一恒：位置=左前；层级=前景；朝向=背对镜头；视线=看对方；对象=林婉儿；占比=42
- 林婉儿：位置=右；层级=中景；朝向=右3-4侧；视线=看对方；对象=叶一恒；占比=50
```

### 3.3 关系（≥2 个角色时**必填**）

| 允许值 | 含义（模型侧英文） |
|---|---|
| 面对面 | the two face each other, eye lines meet |
| 并肩 | standing side by side, both facing the same direction |
| 一前一后 | one behind the other, both facing the same direction |
| 对面而坐 | seated facing each other across a surface |
| 擦肩 | passing each other in opposite directions |
| 背对背 | back to back |

写法：`【关系】面对面`

### 3.4 其他槽（保持自由文本，但受规则约束）

```
【开口】台词开始说的时间，秒（默认 0.8）
【语气】台词怎么说（封闭词表，见下）
【节奏】0.0 起始状态 | 1.4 变化 | 3.0 收尾      ← 秒数递增，最后一拍 < 时长
【场景】固定物件 + 光源
【画质】镜头质感 + 景深 + 皮肤纹理
```

#### 【语气】封闭词表

H3 的语音是模型生成的，"怎么说"只能靠英文描述去带。写 `愤怒地说`、`深情地说` 模型听不懂，
所以只认这 10 个值：

| 写的值 | 编译成 |
|---|---|
| 压低 | in a lowered voice, almost under the breath |
| 急促 | quickly and urgently |
| 发颤 | with a slight tremor in the voice |
| 冷笑 | with a cold, humourless laugh |
| 咬牙 | through clenched teeth |
| 轻描淡写 | lightly, as if it hardly matters |
| 柔和 | softly and warmly, with a smile in the voice |
| 气声 | in a breathy half-whisper |
| 平静 | calmly and evenly |
| 压抑 | restrained, as if holding something back |
| 失控 | losing control of the volume |

不写 `【语气】` 时，编译器按"平静"处理——**这就是为什么台词听起来都一样**。
有台词却没写语气，校验器会提示 `TONE_MISSING`。

## 5. 硬性规则（违反会被拦下）

1. **机位五要素必须齐全**（景别/高度/角度/运镜/距离），缺一个就是不合格。
2. **人物字段必须齐全**（位置/层级/朝向/视线/占比）；`视线=看对方` 时必须有 `对象`。
3. **`对象` 必须是本镜出场角色之一**，不能是画外人。
4. **关系为必填**（≥2 人时）；单人镜不写【关系】。
5. **一镜一个动作**：不要把"对峙 → 转身 → 跑开"写进同一镜，拆成两镜。
6. **台词 ≤ 时长 × 3.8 字**（5 秒 ≤ 15 字）。
7. **节奏最后一拍的时间 < 镜头时长**。
8. **配乐不许写情绪词**（悲伤/紧张/温暖…），只写器乐+速度+节奏。
9. **音效至少两层**（环境 + 动作），不能为空。
10. **chain 只用于同一批人连续动作**；换人就写 cut。人物镜想接上一帧，用「接上一帧」开关，不要靠 chain。
11. **台词之后要么说完就收，要么留 ≥2 个反应节拍**；后半段没有可见动作会被提示 `DEAD_AIR`。
12. **台词的开口时间必须能算得出来**：`【开口】+ 字数 ÷ 3.8 ≤ 时长 - 1`（说完要留余量）。

---

## 5.1 台词时间怎么控制（重要）

> **台词先写成人话，再数字数**（规则 57）。字数不够就补动作，不要补「锅里还有」「我今天也不」这类从句——那不是人话。

> ⚠️ 【节奏】里不要再写「开口说 / 开口喊 / 嘟囔 / 说道」：台词只由【开口】给时间点，重复下指令会让模型多加一个语气词（听着像「诶」）。
> 校验码：`SPEECH_CUE_DUPLICATE`

### 现在唯一的手动开关是【开口】

```
【开口】1.2
   ↓ 编译成
At 00:01.200, 叶一恒 开口说：<d>……</d>。
```

模型看到的是**一句带时间戳的提示**，不是精确指令。**误差通常 0.3–1.0 秒**，越靠后越容易漂。

### 四个层级的可靠性（从低到高）

| 层级 | 做法 | 精确度 | 代价 |
|---|---|---|---|
| ① 提示词 | `【开口】0.8` | **不可靠**：实测偏 0.5 秒到数秒，越靠后越不准 | 0 |
| ② 挂在动作上 | `2.0 他抬眼的同时开口说……` + `【开口】2.0` | 比纯数字稳，但仍会漂 | 0 |
| ③ 结构 | 镜头**从已经在说**开始（`【开口】0.0`） | 最稳（因为不依赖模型算时间） | 要切镜 |
| ④ 后期配音 | 生成时不说话，合成时铺 TTS | ±0.05 秒 | 需要配音轨（目前未实现） |

> **实测结论（2026-11，p_127ieae）**：写了 `【开口】1.2 / 4.0` 的镜头，成片里人声出现的位置
> 都明显晚于写的值，偏差从 0.5 秒到 4 秒不等，且**方向不稳定**。
> 所以：**`【开口】` 只能当"大概在这个动作之后说"，不能当秒表。**
> 需要台词精确落在某个时间点，只有两条路——切镜（③），或后期配音（④）。

### 三条实操建议

1. **把台词绑到动作上**（最划算的一条）：
   ```
   ❌ 2.0 她瞳孔一缩          +  【开口】2.0
   ✅ 2.0 他抬眼的同时开口、目光定在她脸上，她瞳孔一缩   +  【开口】2.0
   ```
   模型对"动作"的响应远比对"数字"精确。

2. **开口尽量靠前**：`0.0–1.2` 最稳；`2.5` 之后开始漂，`4.0` 之后基本不可控。

3. **记住 3.8 字/秒**：
   ```
   15 字 ≈ 3.9 秒   → 适合 5 秒镜（0.8 开口，4.7 说完）
   27 字 ≈ 7.1 秒   → 适合 8 秒镜
   35 字 ≈ 9.2 秒   → 适合 10 秒镜
   ```

### 想让台词"在某一秒准时开口"，只有两个办法

**A. 切镜**（不用后期）

```
不想要：8 秒镜里他在第 5 秒才开口（模型不听话）
要：镜 1 结束在他抬眼，镜 2 一开始就是他说话（开口 0.0）
```

新镜头从这句话开始时，时间就是准的——因为它不需要模型"等到第 N 秒"。

**B. 配音轨**（目前还没实现）

如果两个办法都不接受，那唯一能做到"±0.05 秒"的就是后期配音。
**注意**：背对镜头/侧脸/远景这类看不见嘴的镜头，配音完全没有违和感。

### 什么时候该走后期配音

**看不见嘴的镜头都适合**（背拍 / 侧脸 / 远景 / 过肩背对）：

```
朝向=背对镜头   →  口型不可见  →  台词时间可以 100% 自己控
```

这类镜头让模型生成台词是浪费——它既说不清，时间也不准。后期配音能保证：
- 时间精确到 0.05 秒
- 改台词不用重渲
- 声音清楚

### 说完之后留白，什么时候算问题

校验器的 `DEAD_AIR` 判断标准（2026-11 更新）：

```
台词说完还剩 >1.8 秒
  且 后半段 <2 个节拍  →  报警（画面会停住）
  且 后半段 ≥2 个节拍  →  不报警（有戏的沉默）
```

**"表白完她转身、他嘴角扬起"这种 2.7 秒沉默是加分项，不是问题。**

## 6. 常见错误对照（校验器会这么说）

| 你写的 | 校验器报 | 改法 |
|---|---|---|
| `机位=中景` | `CAMERA_ENUM_MISSING`: 机位缺 高度/角度/运镜/距离 | 补齐五要素 |
| `朝向=斜着看人` | `PERSON_ENUM_INVALID`: 「斜着看人」不在允许值 | 改成 `右3-4侧` 或 `朝向=面向镜头` |
| 两人镜没写关系 | `RELATION_REQUIRED` | 加 `【关系】面对面` |
| `视线=看对方` 没写对象 | `EYELINE_TARGET_MISSING` | 加 `对象=林婉儿` |
| `对象=路人` | `EYELINE_TARGET_NOT_IN_CAST` | 对象必须是本镜角色 |
| `占比=95` | `PERSON_SCALE_RANGE` | 20–80 |
| 一镜写了两个动作 | `MULTI_ACTION` | 拆镜 |
| 配乐写「紧张」 | `MUSIC_MOOD` | 写「低音提琴长音，速度缓慢」 |

## 7. 为什么这些值能控制画面

模型不是"听懂"了中文形容词，而是把这些字段**转成了固定的英文短语 + 参考图权重**：

```
景别=特写 + 距离=0.6   →  close-up, 0.6 meters from the subject
朝向=背对镜头          →  back to camera        （模型不会再画正脸）
视线=看对方/对象=林婉儿 →  looking at Lin Wan'er （明确 eye line）
关系=面对面            →  the two face each other, eye lines meet
```

**关键**：`背对镜头` 这类词对模型来说是强约束——比"他侧过身去"这种散文有效得多。
所以**想让人物面对面，就写关系+互指的对象+3-4 侧脸，不要写"转过身""望着"这种模糊动词。**

## 8. 一个完整示例（可直接复用结构）

```
## 项目
- 片名：三天娶你回家
- 总时长：10 秒（共 2 镜）

## 世界设定
- 视觉语言：Tang dynasty street fair, warm lantern light, 35mm film, shallow depth of field

## 角色卡
### 叶一恒
- 年龄 / 身份：20 岁，镖局少主
- 外观描述：A 20-year-old Chinese young man, hair in a neat topknot with a dark jade pin, no fringe, wearing a white cross-collar changshan with grey bamboo embroidery, grey sash, black cloth boots.
- 一致性锁：束发、无刘海、白色交领长衫
- 服装锁：白色交领长衫 + 灰腰带
- 参考图：3 张

### 林婉儿
