# 2D 动画版：定妆照与场景母版示例

> 配套 `RULES-STRICT.md` 的「2D 动画变体」。这里只给**2D 专用的规格和英文 prompt 示例**。
> 真人版规格见 `CHARACTER-SHEETS.md` / `SCENE-SHEETS.md`——两者的**结构完全一样**，只有画风词不同。

---

## 一、与真人版的四处差异

| 项 | 真人版 | 2D 版 |
|---|---|---|
| 视觉语言 | `35mm film grain, shallow depth of field` | `2D anime, cel-shaded, clean line art, limited palette, hand-drawn background` |
| 【画质】 | 胶片质感 / 真实皮肤纹理 | 赛璐璐上色 / 线稿干净 / 平涂阴影 |
| 微表情 | 毛孔、汗光、皮肤紧致 | 瞳孔高光、眼睑阴影、眉毛角度、口型、发丝 |
| 参考图 | 写实照片 | **必须是 2D 立绘**（混写实图会渲成 3D 动画脸） |

**2D 独有的三条硬要求**

```
1. 线稿粗细统一（同一角色所有图必须同一线重）
2. 上色平涂 + 两层阴影（不要渐变、不要厚涂）
3. 配色表锁定（一件衣服最多 3 个颜色，全剧不能换）
```

---

## 二、角色 2D 立绘规格

| 项 | 要求 |
|---|---|
| 画幅 | 竖构图 **3:4**，全身入画 |
| 背景 | 纯浅灰或米白，**不要场景** |
| 线条 | 干净的深色线稿，线宽均匀，无草稿线 |
| 上色 | 赛璐璐（cel-shaded），每处两档明暗，平涂无渐变 |
| 光 | 均匀正面光，不要戏剧光（2D 立绘要能看出固有色） |
| 风格 | 日本 TV 动画质感，`anime screencap` / `character design sheet` 风格 |
| 禁止 | 3D 渲染感、厚涂、写实皮肤、文字、多人、手遮脸 |

**三视图**：正面 / 侧 3-4 / 背面，**同一套线稿与配色**。

## 五、场景 2D 背景规格

| 项 | 要求 |
|---|---|
| 分辨率 | **1344×768**（等于成片画幅） |
| 内容 | **无人、无文字**，纯背景 |
| 风格 | 手绘动画背景（`hand-painted anime background`），与角色立绘**同一条线重与配色** |
| 距离层 | 前景虚化物件（2D 用"边缘留白/淡出"表现虚化，不要真实景深） |
| 可动元素 | ≥2 个（会由视频模型动起来：灯笼晃、烟、旗、尘） |
| 光 | 明确的方位 + 色温，同一场景所有角度一致 |

**2D 场景与真人场景最大的不同**

```
❌ 不要写 shallow depth of field / bokeh   → 2D 没有真实景深
✅ 用 "foreground element in flat silhouette / soft edge" 表现前后关系
✅ 用色块明暗区分层次，不要用渐变虚化
```

## 七、上传

```
角色 → 场景（左栏）
  定妆照：每人 3 张（正/侧3-4/背），第 1 张为主参考
  场景：母版 1 张 + 追加视角 1 张
```

槽位预算不变：3 人 × 3 张 = 9，就没地方放场景；多人场每人只用 2 张。

## 八、上手顺序（2D 必须这样）

```
第 1 步  场景母版渲 1 个 5 秒单人空镜
         → 只看一件事：画风对不对、线稿抖不抖

第 2 步  单人近景 1 镜（1 张 2D 立绘）
         → 只看一件事：脸崩不崩、颜色跳不跳

第 3 步  两镜都过 → 再按正反打排一整场
```

**为什么必须先试两镜**：2D 在视频模型里比写实更不稳定。常见崩法有三种——

| 崩法 | 表现 | 原因 |
|---|---|---|
| 线条抖 | 轮廓每秒重新描一遍 | 参考图线重不一致 |
| 画风漂移 | 前一秒赛璐璐，后一秒厚涂 | 提示词里混了"电影感/真实材质" |
| 3D 化 | 人脸上出现立体阴影 | 参考图混了写实照片 |

这三种在单镜里能一眼看出来，等到 10 镜终审才发现，全部白渲。
