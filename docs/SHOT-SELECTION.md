# 镜头怎么选 · 表格怎么填（给 Trae 的决策手册）

> 规则卡（`RULES-STRICT.md`）只说了**能用哪些值**，这份说**什么时候用哪个**、**表格怎么填**。
> 写剧本时先看这份，再对照规则卡打勾。

---

## 一、唯一原则：镜头由"这一镜要完成的戏剧任务"决定

```
❌ 先想"这样拍好看"，再找任务
✅ 先写一句话："这一镜要让观众知道/感觉到 ____"
   然后从下表查对应镜头
```

**写不出来这句话 → 这一镜不该存在**（合并到相邻镜）。

---

## 二、戏剧任务 → 镜头对照表

| 这一镜要完成 | 景别 | 高度 | 角度 | 运镜 | 时长 |
|---|---|---|---|---|---|
| **交代空间与人物位置**（每场第一个镜） | 全景 / 中全 | 平视 | 正面 | 固定 或 缓推 | 5 |
| **人物进场 / 离开** | 中全 | 平视 | 正面 / 侧对 | 横向移 或 固定 | 5 |
| **说一句要害的话** | 近景 | 平视 | 正面 / 右3-4侧 | 固定 或 缓推 | 5–8 |
| **听完这句话的反应** | 近景 / 特写 | 平视 | 反打 | 固定 | 5 |
| **下定决心 / 意识到某事** | 近景 | 略仰 | 正面 | 缓推 | 5–8 |
| **被压制 / 弱势 / 无力** | 中景 | 略俯 / 俯拍 | 正面 | 固定 | 5 |
| **揭示道具或线索** | 特写 | 略俯 | 正面 | 固定 或 缓推 | 5 |
| **情绪爆发（吵、哭、吼）** | 特写 | 平视 | 正面 | 手持 | 5 |
| **关系疏离 / 人走开** | 中景 → 中全 | 平视 | 侧对 / 背拍 | 缓拉 | 5–8 |
| **秘密、窥视、别人看不到的视角** | 中景 | 平视 | 过肩-左 / 右 | 固定 | 5 |
| **危险逼近** | 近景 | 略仰 | 正面 | 手持 或 跟拍 | 5 |
| **时间流逝 / 环境呼吸**（空镜） | 全景 或 特写 | 略俯 | 正面 | 固定 或 缓推 | 5 |
| **把两件事剪在一起产生意思** | 交替：特写 + 特写 | 一致 | 一致 | 固定 | 5+5 |

### 三条选镜铁律

1. **建立镜永远用最宽的**（全景/中全），观众先知道"在哪、谁在左谁在右"
2. **情绪转折永远用最近的**（近景/特写），而且要切，不要在同一镜里推过去
3. **信息不在人脸时，就别给人脸**——给道具、给手、给背影

## 三、角度方位怎么选（配对规则）

### 两人对话（正反打）

| 镜头 | 角度 | 朝向 | 说明 |
|---|---|---|---|
| A 正打 | `正面` 或 `侧对-左` | 左3-4侧 | 机位在轴线左端 |
| B 反打 | `反打` 或 `侧对-右` | 右3-4侧 | 机位在轴线右端（同一侧） |

**判据**：两人的 `朝向` 必须镜像相反。写反了剪起来像两人看同一方向。

### 过肩镜

| 写法 | 画面 |
|---|---|
| `过肩-左` | 越过**左边**那个人的肩，看右边的人 |
| `过肩-右` | 越过**右边**那个人的肩，看左边的人 |

被越过的那个人：`层级=前景`、`占比=25–35`（只露肩和后脑）。

### 背拍

| 写法 | 人物在画面里朝 |
|---|---|
| `背拍-左后` | 朝**右上**（机位在他左后方） |
| `背拍-右后` | 朝**左上** |

用途：观众跟着他看，但看不到他的表情（悬念 / 遮掩）。

## 四、运镜幅度（5 秒做不了大动作）

| 时长 | 推/拉幅度 | 横移距离 | 手持 |
|---|---|---|---|
| **5 秒** | 5–8% | 0.5 米以内 | 轻微 |
| **8 秒** | 10–15% | 1 米 | 中等 |
| **10 秒** | 20% | 1.5–2 米 | 明显 |

**一镜只能一种运镜。** 想要"先推后摇"，拆两镜。

## 五、镜头表逐列怎么填

| 列 | 填什么 | 例子 | 常见错误 |
|---|---|---|---|
| **镜号** | `镜 N（Xs）`，X 只能是 5/8/10 | `镜 3（5s）` | 写 6s / 4s |
| **场景** | 场景卡的名字**或** id | `灶房` 或 `kitchen` | 自创"厨房里" |
| **出场角色** | 顿号分隔；空镜写 `无` | `妈妈、小石头` | 写画面外的人 |
| **机位** | 景别+高度+角度+运镜，距离 | `近景+平视+侧对-左+缓推，1.6米` | 缺项；角度不写方位 |
| **动作** | **一句话主动作**（给读者看的摘要） | `把搪瓷盆放进锅里` | 写三个动作 |
| **台词** | `<d>人：话</d>`，对某人说用 `→` | `<d>妈妈→小石头：先吃</d>` | 忘了尖括号；写旁白 |
| **音效** | ≥2 层，用 `；` 分隔 | `雨打窗纸；凉席窸窣` | 只写"环境音" |
| **配乐** | 乐器+速度 或 `无` | `木吉他单音，速度缓慢` | 写"紧张" |
| **转场** | `cut` 或 `chain` | `cut` | 写"淡出" |
| **锚定** | `plate`（用场景母版当首帧）或 空 | `plate` / 空 | 空镜忘了写 plate |

### 「动作」和「节奏」的区别

```
表格「动作」= 一句话摘要，给人看的
prompt「节奏」= 3–5 拍的时间轴，给模型看的
两者不必逐字一致，但「动作」必须是节奏里最大的那件事
```

## 六、完整示例（一场 2 人对白，5 镜）

### 镜头表

```markdown
| 镜号 | 场景 | 出场角色 | 机位 | 动作 | 台词 | 音效 | 配乐 | 转场 | 锚定 |
|---|---|---|---|---|---|---|---|---|---|
| 镜 1（5s） | 灶房 | 妈妈、小石头 | 中全+平视+正面+固定，3.0米 | 妈妈站在门口，小石头蹲在灶前 | 无 | 雨打屋檐；灶膛噼啪 | 无 | cut | 空 |
| 镜 2（5s） | 灶房 | 小石头 | 近景+平视+侧对-左+缓推，1.6米 | 举起烧火棍喊话 | <d>小石头→妈妈：我蒸上米饭了！</d> | 火声；锅盖冒汽的嘶声 | 木吉他分解和弦，速度中快 | cut | 空 |
| 镜 3（5s） | 灶房 | 妈妈 | 近景+平视+反打+固定，1.6米 | 肩膀松下来，嘴角往上提 | 无 | 雨声渐远；湿衣滴水 | 竹笛单音，速度缓慢 | cut | 空 |
| 镜 4（5s） | 灶房 | 妈妈 | 近景+平视+侧对-右+固定，1.5米 | 把油纸包按进他手心 | <d>妈妈→小石头：先吃。</d> | 油纸窸窣；手背擦过脸颊 | 竹笛单音，速度缓慢 | cut | 空 |
| 镜 5（5s） | 灶房 | 小石头 | 特写+略俯+正面+固定，0.9米 | 低头看油纸包 | <d>小石头：妈，你也吃。</d> | 油纸被捏紧；锅里的咕嘟声 | 木吉他单音，速度缓慢 | cut | 空 |
```

### 对应的两镜 prompt（示范正反打）

```markdown
### 镜 2
【机位】景别=近景；高度=平视；角度=侧对-左；运镜=缓推；距离=1.6
【人物】
- 小石头：位置=中；层级=中景；朝向=右3-4侧；视线=看画外；占比=60
【语气】急促
【开口】0.6
【节奏】0.0 他蹲在灶前、手里攥着烧火棍、指甲缝全是黑灰 | 0.8 猛地回头、烧火棍往门口一指 | 2.0 喊出声、脖子上的筋绷起来 | 3.4 灶膛的火在他眼睛里跳、他咧嘴笑了一下 | 4.4 锅盖被汽顶得轻响、他缩了缩脖子
【场景】左侧土灶台与大铁锅、中间柴堆（前景虚化垂下的麻绳）、右侧门框与雨帘；灶膛暖火从下方来、门外冷光从右侧勾边
【画质】35mm 胶片质感、浅景深、真实皮肤纹理、火光在脸上的暖边

### 镜 3
【机位】景别=近景；高度=平视；角度=反打；运镜=固定；距离=1.6
【人物】
- 妈妈：位置=中；层级=中景；朝向=左3-4侧；视线=看对方；对象=小石头；占比=55
【语气】无
【节奏】0.0 她站在门口、湿发贴着额角、怀里还护着油纸包 | 1.2 肩膀慢慢松下来、呼吸放长 | 2.6 嘴角往上提了一点、眼睛弯起来 | 4.0 抬手把额前的湿发拨到耳后
【场景】左侧门框（前景虚化）、中间灶房地面、右侧灶台的暖光；门外的冷天光从背后勾边、灶火从右侧补暖
【画质】35mm 胶片质感、浅景深、湿发与湿衣的质感、逆光下的发丝
```

**对照着看**：

| | 镜 2（A 说） | 镜 3（B 反应） |
|---|---|---|
| 景别/高度/距离 | 近景 / 平视 / 1.6 | **完全一致** |
| 角度 | 侧对-左 | **反打**（相反一侧） |
| 朝向 | 右3-4侧 | **左3-4侧**（镜像） |
| 运镜 | 缓推（他在发力） | 固定（她在松动） |
| 台词 | 有 | 无（但她有反应） |

## 七、常见错配（自查）

| 错配 | 后果 | 改法 |
|---|---|---|
| 建立镜用特写 | 观众不知道在哪 | 换全景/中全 |
| 反应镜用中全 | 看不到表情 | 换近景 |
| 要害台词用背拍 | 看不到嘴，像旁白 | 换正面/侧对 |
| 情绪爆发用固定 | 没有冲击 | 换手持 |
| 5 秒里做大横移 | 糊成一片 | 拆两镜或改固定 |
| 关键信息靠微表情 | 模型画不出 | 换道具特写/动作 |
| 一镜里又推又摇 | 模型只做一个 | 拆两镜 |
| 空镜没写 plate | 场景对不上 | 锚定=plate |

## 八、给 Trae 的一句话

```
不要问"这个镜头好不好看"，先写"这一镜要让观众知道什么"，
再从《戏剧任务 → 镜头对照表》里查一行，照着填。
填完用第七节的错配表自查一遍。
```

> 运镜合法值：固定 / 缓推 / 缓拉 / 横移 / 跟拍 / 手持 / 环绕-左 / 环绕-右。
> `环绕` 实测上限约 30°，大角度环绕要靠多镜拼接。
