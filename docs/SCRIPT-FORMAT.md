# 剧本格式

一份 Markdown，直接导入。格式固定，但字段宽容（缺字段用默认值，不会报错）。

---

## 最小可导入版本

```markdown
## 项目
- 片名：夜班
- 总时长：10 秒（共 2 镜 × 5 秒）

## 场景卡
### 场景 1：采样舱
- 机位：样本台后方平视
- 固定物件：样本台中、样本柜左、舷窗右
- 光源：顶部冷白 + 左侧冷青

## 镜头表
| 镜号 | 场景 | 出场角色（≤3） | 景别 / 机位 / 运动 | 空间锚点 | 动作 | 台词 | 转场 | 锚定 |
|---|---|---|---|---|---|---|---|---|
| 镜 1（5s） | 采样舱 | 无（空镜） | 中景平视固定 | 台中、柜左、窗右 | 指示灯呼吸 | 无 | cut | plate |
| 镜 2（5s） | 采样舱 | 阿澈 | 近景轻推 | 同上 | 抬手触碰夹具 | <d>阿澈：矿脉在脉冲。</d> | chain | 空 |
```

---

## 字段说明

### 项目
| 字段 | 必填 | 说明 |
|---|---|---|
| 片名 | ✅ | 项目标题 |
| 总时长 | — | 仅显示，不参与计算 |
| 空间数量 | — | 仅描述 |

### 角色卡（每个角色一段，`- 名字：` 开头）
| 字段 | 说明 |
|---|---|
| 名字 | **必须与镜头表里写的一字不差**；支持 `Ye Qian（叶谦）` 这种双语写法，导入时自动取中文 |
| 年龄 / 身份 | 进提示词 |
| 英文外观描述 | 只写看得见的固定特征（脸型/发型/服装/配饰），60–100 词 |
| 一致性锁 | 3–5 个不可变特征词 |
| 服装锁 | 一句话 |

> 角色卡只创建记录，**参考图要在界面上传**（1–4 张/人）。

### 场景卡
| 字段 | 说明 |
|---|---|
| 机位 | 在哪 / 朝哪 / 高度 / 常用景别 |
| 固定物件 | 3–6 个，写清在画面左/中/右的位置 |
| 光源 | 方向 / 色温 / 明暗 |
| 母版镜头号 | 该空间空镜建立镜头是第几镜（用于对应母版图） |

### 镜头表
| 列 | 说明 |
|---|---|
| 镜号 | `镜 1（5s）` 或 `s01`；按出现顺序编号 |
| 场景 | 场景卡的名字；也可写 `（id：scene_a）` 指定 id |
| 出场角色 | ≤3 个，用 `、`/`,` 分隔；空镜写 `无（空镜）` |
| 景别 / 机位 / 运动 | 进提示词 |
| 空间锚点 | 机位 + 3 个物件位置 + 光，越具体越稳 |
| 动作 | **只写一个**动词短语 |
| 台词 | `无` 或 `<d>角色：台词</d>`；≤24 汉字 |
| 转场 | `cut` 或 `chain`（见下） |
| 锚定 | `plate`（用场景母版当首帧，只对空镜）或 `空` |

### 每镜提示词（可选但强烈建议）
五段式，导入时优先用它，没有则用镜头表拼：

```
【场景锚点】……（机位、3 个物件位置、光）
【角色】……（名字 + 外观锁）
【动作】……
【光线】……
【画质】35mm 胶片质感，浅景深
```

---

## 转场怎么选（最容易错的地方）

| 情况 | 用 |
|---|---|
| 同一批人、动作连续、幅度小 | `chain` |
| **换人 / 换机位 / 动作幅度大（砸、刺、跑）** | **`cut`** |
| 第一镜 | `cut`（必须） |

> **踩坑实测**：8 镜全部用 `chain` 时，后 4 镜首帧相似度 0.94–0.99，整片变成一条几乎不动的长镜头。
> 原因：chain 把首帧逐像素锁在上一镜末帧，模型只能微动。
> 界面上的「按角色自动设转场」会按"角色集合是否变化"自动选 cut/chain。

## 让大模型写剧本的提示词

把下面这段整段粘给 DeepSeek / GPT，末尾替换成你的故事：

```text
你是一名短剧分镜编剧兼 AI 视频提示词工程师。请严格按下面的格式输出一份可直接导入的生产剧本。

硬性约束：
1. 每镜 5 秒，全片 5–8 镜。
2. 第 1 镜必须是空镜建立镜头（cut + 锚定 plate）；第 2 镜起：同一批人连续动作才用 chain，换人或大动作一律 cut。
3. 每镜只写一个动作（最多两个）。
4. 横屏 16:9（1344×768），禁止竖屏参数。
5. 每镜出场角色最多 3 人；空镜写「无（空镜）」。
6. 台词每句不超过 24 个汉字。
7. 角色名前后完全一致；如需双语，写成 `Ye Qian（叶谦）`。
8. 同一空间内机位、固定物件、光线保持一致。
9. 不写粒子/能量/爆炸/激光；特效只用光线描述。
10. 不写"镜头向左转"，改写"地平线右高左低"或"元素从画面两侧掠过"。

按以下结构输出：

## 项目
- 片名：
- 一句话故事：
- 总时长：__ 秒（共 __ 镜 × 5 秒）

- 色彩脚本：主色 / 辅色 / 高光色
- 时间 / 天气 / 光线：

## 角色卡
- 名字：
- 年龄 / 身份：
- 英文外观描述：
- 一致性锁：
- 服装锁：

## 场景卡
### 场景 1：（地点）
- 机位：
- 固定物件：
- 光源：
- 母版镜头号：镜 1

## 镜头表
（九列表格：镜号 | 场景 | 出场角色 | 景别/机位/运动 | 空间锚点 | 动作 | 台词 | 转场 | 锚定）

## 每镜可执行 prompt
（每镜五段式）
```

## 导出

`GET /api/projects/{id}/export/markdown` 导出为同一格式（含 `锚定` 列与 `（id：scene_x）`），
**可以再次导入**，角色/场景不会重复创建——往返有测试覆盖。
