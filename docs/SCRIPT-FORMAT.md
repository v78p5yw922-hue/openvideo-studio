# 剧本契约（SCRIPT-FORMAT v2）

> 这份文档是**唯一标准**。UI 的校验器（`studio/core/validate.py`）逐条实现它。
> 你的剧本只要通过校验，就能直接渲染；不通过时，UI 会指出是哪一镜、错在哪、怎么改。

---

## 1. 为什么要有契约

视频模型不会"理解剧情"，它只执行**可见/可听清单**。所以剧本必须同时承担两件事：

| 层 | 谁写 | 内容 |
|---|---|---|
| **剧本层**（人 / DeepSeek） | 中文 Markdown，6 个段落 | 故事、角色、场景、镜头表 |
| **投喂层**（编译器） | 机器生成 | H3 原生三字段 + 人数约束 |

**你永远不写投喂层**。你只按本文档写剧本层，编译器负责翻译。

---

## 2. 六个段落（顺序固定）

```markdown
## 项目
## 世界设定
## 角色卡
## 场景卡
## 镜头表
## 每镜 prompt
```

### 2.1 项目

```markdown
## 项目
- 片名：三天娶你回家
- 总时长：35 秒（共 7 镜 × 5 秒）
```

### 2.2 世界设定（**只写风格，不写角色**）

```markdown
## 世界设定
- 视觉语言：warm temple fair, Tang-style street, soft daylight, 35mm film, shallow depth of field, natural skin texture
```

✅ 可以写：年代感、色调、光线、镜头质感、画幅、整体类型
❌ **禁止写**：角色姓名、角色服装、角色长相、具体道具细节

> **为什么**：视觉语言会拼进**每一镜**的提示词。写一套衣服，模型就多画一个人；
> 写三套衣服，就会出现"四个人并排"。

### 2.3 角色卡（一个角色一张卡，服装写这里）

```markdown
## 角色卡

### 叶一恒
- 年龄 / 身份：20 岁，镖局少主
- 外观描述：A 20-year-old Chinese young man, short black hair with a soft fringe, fair skin, gentle and quiet expression. Wearing a white linen mandarin-collar jacket with frog buttons, grey turtleneck underneath, grey wool trousers, black leather shoes. Slim build, upright posture.
- 一致性锁：短发、凤眼、瘦高
- 服装锁：白色立领亚麻长衫 + 灰色高领毛衣
- 参考图：3 张（正面 / 四分之三 / 侧面，同一套服装同一光线）

### 林婉儿
- 年龄 / 身份：22 岁，镖局大小姐
- 外观描述：Female, 22, round-oval face with clear dark eyes, high ponytail tied with a red ribbon, a small old scar on the right cheek, wearing an indigo narrow-sleeved martial short jacket.
- 一致性锁：马尾红绳、右颊浅疤
- 服装锁：靛青窄袖短打
- 参考图：需要 1–3 张
```

**要求**
- 「外观描述」必须用英文写（模型对英文外观词更稳定）
- 每个要出场的角色**至少 1 张参考图**，最好 3 张（正面 / 四分之三 / 侧面，同一套服装）
- 0 张参考图 → 校验器报 `CAST_NO_REF`（阻断）

### 2.4 场景卡

```markdown
## 场景卡

### 场景 1：庙会街（id：temple_fair）
- 机位：平视 3 米
- 固定物件：左红灯笼架、中青石路、右糖画摊
- 光源：暖日光，从右前上方来
- 母版镜头号：镜 1
```

- 想用「锚定=plate」的镜头，该场景**必须有母版图**，否则报 `PLATE_MISSING`
- 母版图就是这一镜的首帧参考：上传后，空镜会从这张图起步

### 2.5 镜头表（10 列，表头必须原样）

```markdown
| 镜号 | 场景 | 出场角色 | 景别/机位 | 动作 | 台词 | 音效 | 配乐 | 转场 | 锚定 |
|---|---|---|---|---|---|---|---|---|---|
| 镜 1（5s） | 庙会街 | 无（空镜） | 中景平视固定 | 空镜建立 | 无 | 街市人声隐约，风过灯笼 | 无 | cut | plate |
| 镜 2（5s） | 庙会街 | 叶一恒、林婉儿 | 中景双人，左右对望 | 叶一恒拱手 | <d>叶一恒→林婉儿：三天之内，我娶你回家</d> | 折扇合拢，衣料摩擦 | 低音提琴长音，速度缓慢 | cut | 空 |
```

**列定义**

| 列 | 必填 | 规则 |
|---|---|---|
| 镜号 | ✅ | `镜 N（5s）`；秒数可写 4–15，**默认 5**。时长直接决定能装多少台词 |
| 场景 | ✅ | 必须是「场景卡」里的名字 |
| 出场角色 | ✅ | 「无（空镜）」或 1–3 个名字，用、分隔；**超过 3 个报错** |
| 景别/机位 | ✅ | 景别 + 机位 + 运动，如「中景平视固定」「近景平视轻推」 |
| 动作 | ✅ | **一镜只写一个动作**（砸、刺、快速转身会失败） |
| 台词 | ✅ | `无` 或 `<d>说话人：台词</d>`；对某人说就写 `<d>说话人→对象：台词</d>` |
| 音效 | ✅ | 画面世界里的声音；没有写「无」 |
| 配乐 | ✅ | 只写乐器/速度/节奏；**禁止情绪词**；没有写「无」 |
| 转场 | ✅ | `cut`（切）或 `chain`（接上一镜末帧） |
| 锚定 | ✅ | `plate`（用场景母版当首帧，只用于空镜）或 `空` |

### 2.6 每镜 prompt（六槽，一镜一块）

```markdown
## 每镜 prompt

### 镜 2
【机位】中景平视固定，距人物 2.5 米
【人物】叶一恒 | 画面中 | 占画幅 60% | 朝右前
【节奏】0.0 站定合扇 | 1.8 合扇收势 | 3.0 切近景，拱手作揖 | 4.3 抬眼看向对面
【场景】左红灯笼架、中青石路、右糖画摊；暖日光从右前上方来
【画质】35mm 胶片质感，浅景深，真实皮肤纹理
```

**要求**
- 五个槽必须都有（缺【动作】会报 `NO_ACTION`，缺全部会报 `PROMPT_NO_SLOTS`）
- 【人物】只写这一镜真正出场的人，**数量必须和镜头表一致**
- 【动作】写一个连贯动作（起 → 止），不写心理活动

---

## 2.7 【节奏】——让模型知道"第几秒做什么"

这是让单镜不"空"的关键。写法：`秒数 描述`，用 `|` 分隔，秒数递增。

```
【节奏】0.0 站定合扇 | 1.8 合扇收势 | 3.0 切近景，拱手作揖 | 4.3 抬眼看向对面
```

编译器会翻译成 H3 的时间轴语法：

```
[Shot 1] ... 开场：站定合扇。
At 00:01.800, 合扇收势。
At 00:03.000, the camera cuts to 近景，拱手作揖。
At 00:04.300, 抬眼看向对面。
```

规则：
- `0.0` 那个节拍是这个镜头的**起始状态**
- 描述里带「切 / 特写 / 近景 / 中景 / 全景 / 俯 / 仰」的节拍，会自动变成**镜头切换**（the camera cuts to）
- 最后一个节拍必须 **小于镜头时长**，否则报 `BEAT_OVERRUN`
- 有时长轴就不用再写【动作】（写了也会被忽略，避免重复）

## 2.8 每个 5 秒怎么才算"饱满"

空镜不是必需。**每个 5 秒镜至少要有一个"变化"**，否则观众会觉得在放 PPT。

### 三拍法（推荐）

```
0.0 ── 起（状态/悬念）
1.7 ── 变（动作/转折/台词落点）
3.4 ── 收（反应/新信息，把观众推向下一镜）
```

写进【节奏】：

```
【节奏】0.0 背对镜头站着 | 1.7 猛然转身 | 3.4 合扇，抬眼直视对面
```

### 五种"变化"素材（任选一种就够）

| 类型 | 例子 | 为什么有效 |
|---|---|---|
| **反转动作** | 站定 → 猛然转身 | 观众预期落空 |
| **打断** | 话说到一半被人按住肩 | 制造悬念 |
| **道具强调** | 手指捻一下公文 / 合扇 | 给台词加重音 |
| **视线转移** | 看向画面外 → 瞳孔一缩 | 暗示有人来了 |
| **景别切换** | 中景 → 切近景 | 用剪辑制造压迫感 |

### 坏例子 vs 好例子

```markdown
# ✗ 太空：5 秒只有一个人站着
【节奏】0.0 站在街上 | 4.0 还站在街上

# ✓ 饱满：5 秒三个信息
【节奏】0.0 背对镜头，肩线紧绷 | 1.7 猛然转身，衣摆带风 | 3.4 合扇，抬下巴，直视对面
```

### 空镜怎么用

- 一个空镜**最多 1.5 秒**，作为下一镜的开场节拍（`0.0 空街 | 1.5 叶一恒入画`）
- 单独占一整个 5 秒的空镜 → 校验器报 `EMPTY_SHOT` 警告

## 3. 硬规则（违反会被校验器拦下）

1. **视觉语言里不许出现角色服装**（`STYLE_COSTUME`，阻断）
   服装只写在角色卡；否则模型给每套衣服各画一个人。

2. **台词必须装得进镜头时长**（`DIALOGUE_TOO_LONG`，阻断）

   实测语速 **3.8 字/秒**（edge-tts 中文，含停顿）。可用字数 = 时长 × 3.8 − 1。

   | 时长 | 最多台词 |
   |---|---|
   | 5 秒 | 15–18 字 |
   | 8 秒 | 27–29 字 |
   | 10 秒 | 35–37 字 |

   装不下就**拆镜**或**加长**（写 `镜 N（8s）`）。

13. **一镜只放一个语气转折**（`DIALOGUE_MULTI_SENTENCE`，警告）
   两句以上台词建议拆成两镜。

12. **出场角色 ≤ 3 人**（`CAST_TOO_MANY`，阻断）
   双人镜头已经是 H3 的舒适上限；三人及以上脸容易糊。

3. **每个出场角色必须有参考图**（`CAST_NO_REF`，阻断）
   0 张参考图 = 人脸随机。

4. **台词的说话人必须在本镜出场角色里**（`DLG_SPEAKER_NOT_IN_CAST`，阻断）

5. **台词写了对象（A→B），对象也必须在本镜出场角色里**（`DLG_TARGET_NOT_IN_CAST`，阻断）
   否则画面里没人可看，台词变成对着空气说。

6. **锚定=plate 时，场景必须有母版图**（`PLATE_MISSING`，阻断）

7. **场景必须存在于场景卡**（`SCENE_UNKNOWN`，阻断）

8. **一镜只做一个动作**（超过会失败，这是 H3 的实测限制）

9. **chain 只用于同一主体连续动作**（`CHAIN_CAST_CHANGE`，警告）
   换人还 chain = 画面几乎静止。UI 有「按角色自动设转场」一键修。

10. **配乐不写情绪词**（`MUSIC_MOOD`，警告）
    写「低音提琴长音，速度缓慢」，不写「悲伤」。

11. **跨镜对话要么整句落在同一镜，要么在台词末尾写 `…`**（表示没说完，话音带进下一镜）
    分开生成的两个 5 秒镜，音频是各自独立的；想让一段对话**完全连贯**，
    最好写成**一个 10–15 秒的镜头**，内部用【节奏】切两次。

12. **节拍时间不能超过镜头时长**（`BEAT_OVERRUN`，阻断）

13. **不要在输出末尾附自检清单**；如果一定要附，单独一行以 `【自检】` 开头。

## 3.5 镜头密度（别指望单镜很复杂）

H3 一镜只能做一个动作，所以信息量靠**镜头数量**堆，不靠单镜时长：

| 成片长度 | 建议镜数（5 秒/镜） |
|---|---|
| 15 秒 | 3 镜 |
| 30 秒 | 6 镜 |
| 60 秒 | 12 镜 |
| 3 分钟 | 36 镜 |

**空镜（第 1 镜）不是浪费**：它给母版图一个落点、给观众交代空间。但连续两镜空镜就该合并。

## 4. 校验器规则速查（对着改）

| code | 级别 | 含义 | 怎么改 |
|---|---|---|---|
| `STYLE_COSTUME` | 阻断 | 视觉语言混入角色服装 | 把服装移到角色卡 |
| `CAST_TOO_MANY` | 阻断 | 出场角色 > 3 | 拆镜或删人 |
| `CAST_UNKNOWN` | 阻断 | 角色不在角色库 | 补角色卡 |
| `CAST_NO_REF` | 阻断 | 角色没有参考图 | 上传 1–3 张 |
| `SCENE_UNKNOWN` | 阻断 | 场景不存在 | 补场景卡 |
| `PLATE_MISSING` | 阻断 | 锚定 plate 但没母版 | 上传母版或改锚定 |
| `DLG_NO_SPEAKER` | 阻断 | 台词没写说话人 | 改 `<d>名字：台词</d>` |
| `DLG_SPEAKER_NOT_IN_CAST` | 阻断 | 说话人不在本镜 | 加进「出场角色」 |
| `DLG_TARGET_NOT_IN_CAST` | 阻断 | 台词对象不在本镜 | 加人 / 改独白 / 拆反应镜 |
| `DURATION_RANGE` | 阻断 | 时长不在 4–15 秒 | 改镜号里的秒数 |
| `DIALOGUE_TOO_LONG` | 阻断 | 台词装不进这一镜 | 删字或加长镜头 |
| `DIALOGUE_MULTI_SENTENCE` | 警告 | 一镜多句台词 | 拆镜 |
| `EMPTY_SHOT` | 警告 | 无人物且无节奏，5 秒太空 | 加人物或加三拍节奏 |
| `BEAT_OVERRUN` | 阻断 | 节拍时间超过镜头时长 | 节拍前移或加长镜头 |
| `BEAT_UNSORTED` | 警告 | 节拍时间不是递增 | 按 0.0/1.8/3.0 顺序写 |
| `DLG_SELF` | 警告 | 说话人=对象 | 改自语言 |
| `NO_CAMERA` | 警告 | 没写机位 | 补「景别/机位」 |
| `PROMPT_NO_SLOTS` | 警告 | prompt 不是五槽 | 按五槽重写 |
| `NO_ACTION` | 警告 | 没写动作 | 补【动作】 |
| `EMPTY_SHOT_MENTIONS_CHAR` | 警告 | 空镜 prompt 提到角色 | 加 cast 或删人物描述 |
| `CHAIN_CAST_CHANGE` | 警告 | chain 但换人 | 改 cut |
| `MUSIC_MOOD` | 警告 | 配乐写情绪词 | 改成器乐描述 |

## 5. 给 DeepSeek 的提示词（整段复制）

```text
你现在是一名短剧分镜编剧。请严格按下面格式输出一个完整剧本，不要输出任何解释。

【输出结构】必须且只能包含这六个二级标题，顺序不变：
## 项目
## 世界设定
## 角色卡
## 场景卡
## 镜头表
## 每镜 prompt

【项目】
- 片名：<片名>
- 总时长：<N> 秒（共 <N> 镜 × 5 秒）

【世界设定】
- 视觉语言：只写年代感、色调、光线、镜头质感、整体类型（英文逗号分隔）。
  严禁写任何角色姓名、角色服装、角色长相、具体道具。

【角色卡】每个角色一张卡，格式：
### 角色名
- 年龄 / 身份：
- 外观描述：用英文写（年龄、脸型、发型、肤色、表情、服装、鞋、体态）
- 一致性锁：3–5 个不变特征
- 服装锁：这一部戏穿的服装
- 参考图：需要几张

【场景卡】每个场景一张卡，格式：
### 场景 N：场景名（id：英文id）
- 机位：
- 固定物件：
- 光源：
- 母版镜头号：镜 N

【镜头表】表头必须原样使用这十列：
| 镜号 | 场景 | 出场角色 | 景别/机位 | 动作 | 台词 | 音效 | 配乐 | 转场 | 锚定 |
|---|---|---|---|---|---|---|---|---|---|

规则：
1. 出场角色 1–3 人，空镜写「无（空镜）」
2. 台词格式 <d>说话人：台词</d>；如果是对某人说，写 <d>说话人→对象：台词</d>，且对象必须在本镜出场角色里
3. 台词说话人也必须在出场角色里
4. 一镜只写一个动作
4b. 镜号写成「镜 N（Xs）」，X 取 4–15；5 秒镜的台词不超过 15 字，8 秒不超过 27 字
4c. 每个镜头都必须有变化：不要写没有人物、没有动作转折的空镜。空镜最多 1.5 秒，并作为下一镜的开场节拍
5. 音效写画面世界里真实的声音（风、脚步、布料、器皿），没有写「无」
6. 配乐只写乐器 + 速度 + 节奏，严禁写情绪词（悲伤/紧张/温暖/压抑），没有写「无」
7. 转场只能是 cut 或 chain；chain 只能用于「同一批人连续动作」
8. 锚定只能是 plate 或 空；plate 只能用于空镜，且该场景必须已有母版

【每镜 prompt】每一镜一块，严格六槽（【节奏】用来写镜内时间轴）：
### 镜 N
【机位】景别 + 机位 + 距离 + 运动
【人物】角色名 | 位置 | 占画幅比例 | 朝向（多人用分号隔开）
【节奏】0.0 起始状态 | 1.5 动作一 | 3.0 切到什么 | 4.3 收尾（秒数递增，最后一个小于时长）
【场景】固定物件 + 光源
【画质】镜头质感 + 景深 + 皮肤纹理

【硬性禁止】
- 禁止把角色服装写进「视觉语言」
- 禁止超过 3 个出场角色
- 禁止一镜多个动作
- 禁止在末尾附加自检清单
- 禁止输出解释性文字
```

## 7. UI 如何执行这份契约

| 环节 | 行为 |
|---|---|
| 导入剧本 | 解析 → 落库 → 立即跑一次校验，把 error/warn 显示出来 |
| 就绪条（顶部） | 有 error 时红色列出（带修改建议），并**阻断生成** |
| 生成计划 | 计划里合并校验结果；有 error 直接返回 400 |
| 渲染 | 编译器按契约生成三字段，自动加人数约束、剔除风格里的服装词 |
