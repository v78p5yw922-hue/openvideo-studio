# 审稿已知坑位（REVIEW-LESSONS）

> 每一条都是**真实打回过的**。审稿时逐条比对，别让同一类问题再出现。
> writer 写之前也该扫一眼。新增条目请按「现象 / 原因 / 写法」三行记。

---

## 1. 熟食画成生肉

```
现象   猪脸肉在画面里出现多次，全是生的、不像
原因   只写"切好的猪脸肉、肥瘦相间"，没写熟度
写法   卤好的猪脸肉、酱红色、油亮、切成薄薄的小片、一片片码着、冒着热气
```

## 2. 台词说完画面停太久

```
现象   "妈你上哪去了"之后 2.7 秒几乎没有动作
原因   台词的语速按 3.8 字/秒算，说完后没安排节拍
写法   说完后至少两拍：脖子往前伸 → 目光落到她手里的油纸包 → 脚跟在门槛上蹭
```

## 3. 台词复述画面

```
现象   "给你买的猪脸肉"多余
原因   画面已经在递包，台词又报一遍
写法   "刚从菜园回来。"（信息交给画面；台词只说意图/情绪/关系）
```

## 4. 锅盖没开就倒油

```
现象   炒菜镜头，锅盖还盖着就倒油
原因   写了后续动作，没写前置
写法   掀开锅盖、白汽腾起、锅盖立在灶台边 → 再倒油
```

## 5. 场景卡写"破一角"，模型画了破洞

```
现象   窗户有破洞；还多出一辆三轮车经过
原因   场景卡写了"窗纸破一角"；节奏写了"窗纸上晃过推车的影子"
写法   场景卡只写会入画的固定物件（窗纸完好）；氛围写进【画质】；
       不要写"影子/映出/晃过"这种会被实体化的描述
```

## 6. 没睁眼就说话

```
现象   他睡着，台词已经出来了
原因   开口时间 1.6s，但节奏里 1.8s 才坐起来
写法   0.0 还在睡 → 1.0 睁眼眨眼 → 2.2 坐起 → 3.4 才开口
```

## 7. 端着盆去够火柴 / 火柴像树枝

```
现象   手上还端着搪瓷盆就去拿火柴；火柴被画成树枝粗细
原因   没写"盆放下"；火柴没写尺寸材质
写法   把搪瓷盆放到灶台边 → 手在裤子上擦两下 → 抽出一根红头细火柴
```

## 8. 熟食不该系绳子

```
现象   油纸包上出现麻绳（剧本里没有）
原因   我们自己编了细节，且与常识冲突（熟食摊不会系绳）
写法   暗黄油纸四角对折、没有绳子、油渗出一点
```

## 9. 递东西变成握手

```
现象   手递手的镜头，两只手握在一起，看不见肉
原因   "递"没写宾语形态
写法   两指捏起一片薄肉、肉片垂下来、油光晃了一下 → 递出去
```

## 10. 穿着凉鞋睡觉，掀被子后鞋消失

```
现象   睡着时脚上穿着红凉鞋，掀被子后鞋不见了
原因   服装锁写死"始终穿红凉鞋"，节奏又写"光脚"→ 模型先穿后抹
写法   服装锁：红凉鞋只在出屋时穿，在炕上赤脚；
       0.0 两只凉鞋并排摆在炕沿下（入画）→ 8.4 光脚伸到炕沿外、脚趾碰到鞋面
```

## 通用规律（从这 10 条里提炼）

```
① 模型只看到你写的字，不补常识 → 状态/前置/去向必须明写
② 写进节奏里的"声音"会被念成旁白 → 声音只写【音效】
③ 台词是"说不出来的部分"，不是画面解说
④ 道具要有生命周期：出现 → 移动 → 落点
⑤ 任何"映出/影子/晃过"都会被实体化，别用来暗示氛围
```

## 11. 特写里只写「卤好的」不够 —— 要给外观词

```
现象   s10 是 1.2 米特写（手指捏着肉片），prompt 里写了「卤好的」，渲出来仍像生肉
原因   「卤好的」是语义词，模型对"熟"的颜色映射不稳定；
       而 s09 远景写了「酱红色、油亮、一片片码着」就明显像熟的
写法   特写镜必须给外观三件套：颜色（酱红/焦褐）+ 光泽（油亮/挂着汁）+ 质感（胶质/肥的透亮）
       例：酱红色、油亮、边缘半透明的胶质、肥的那块透亮
教训   状态词分两类——语义词（熟的）不可靠，外观词（酱红油亮）才可靠；
       越近的镜头越要写外观。

## 12. 走路像老太太 —— 只写"走"没写步态

```
现象   8 岁男孩从卧室走出来，姿势像老太太：弓背、小碎步、慢慢挪
原因   节奏只写「站起来、走出卧室门、扶了一下门框」，没有任何步态词；
       而且「扶门框」本身给了模型一个"虚弱"的暗示
写法   步态三要素必须写全：步幅（步子小而快）+ 频率 + 上身（上身前倾、肩膀不塌、不弓背）
       例：上身前倾、步子小而快、两脚略微外八、肩膀是软的但不弓背
       刚睡醒的状态单独写：下巴低着、眼睛半睁、手背蹭眼睛
       把「扶门框」改成「手在门框上撑一下就松开」——撑一下就松，不是靠着
```

## 13. 成年人和孩子同框，中全把大人的头顶切掉

```
现象   s01 里妈妈只剩下半身 / 头顶被上边缘切掉，台词被判给小石头
原因   中全 + 3.0 米拍 1.7 米的大人和 1.2 米的孩子：模型会让大人贴近镜头，
       头顶先出画；没有脸的说话人 = 台词自然分给画内唯一有脸的人
写法   ① 一大一小同框，景别用全景、距离 ≥4.0 米
       ② 场景里写死 headroom：「从头顶到脚都在画面内，头顶上方留出一段空隙」
       ③ 大人占比别超过 35%（占比越大越容易贴近镜头）
       ④ 有台词的镜，先说清楚"说话的是谁、另一个人的嘴闭着"
```

## 14. 人物朝向和"目标"打架：背对目标却指着目标

```
现象   s03 里两个人背对白色房子、却抬手指着它，然后"转身"往它走 —— 观众看不懂
原因   机位写"正面"、人物写"面向镜头"（=背对白墙），但动作是"抬手指向白墙"
       → 方向自相矛盾；再写"转身跑过去"，就变成先背对、再折返
写法   走向某个目标时：机位放人物**身后**，人物写【朝向】背对镜头、
       视线看画外，目标在画面深处；"回头"就是真的转身回看（不是折返）
       背对镜头的说话人在编译时会自动变成画外音（不对口型）
```
