# 分镜硬规则（Trae 严格执行版）

> 每条都是**可判定的**：满足就是通过，不满足就是错。
> 写之前不要读别的，就按这 53 条逐条过。
> 完整说明见 `CONTENT-BRIEF.md`；本文只列规则。
> **不知道怎么选镜头 / 表格怎么填** → 看 [`SHOT-SELECTION.md`](SHOT-SELECTION.md)（戏剧任务→镜头对照表 + 逐列填法 + 完整示例）。

---

## A. 结构（6 条）

1. 六个二级标题，顺序固定：`## 项目` `## 世界设定` `## 角色卡` `## 场景卡` `## 镜头表` `## 每镜 prompt`
2. 角色卡里每个角色以 `### 角色名` 开头（**不能省**，否则该角色不建卡）
3. 场景卡里每个场景以 `### 场景 N：名字（id：英文小写下划线）` 开头
4. 镜头表表头原样：`| 镜号 | 场景 | 出场角色 | 机位 | 动作 | 台词 | 音效 | 配乐 | 转场 | 锚定 |`
5. 每个表行必须有一个对应的 `### 镜 N` prompt 段，且 N 与表里的镜号一致
6. 镜头表里的镜号写 `镜 N（Xs）`，X 只能是 5 / 8 / 10

## B. 时长（2 条）

7. 时长只能是 **5 / 8 / 10** 秒
8. 台词字数上限：5 秒 ≤15 字 · 8 秒 ≤27 字 · 10 秒 ≤35 字

> 写 4/6/7/9 会被吸附成 3.75 / 5.88 / 7.29 / 8.71 秒，节奏表会算错，所以禁止。

## C. 机位与运镜（8 条）

9. 五要素齐全：`景别 / 高度 / 角度 / 运镜 / 距离`，缺一即错
10. 角度必须带方位：`过肩-左|过肩-右|侧对-左|侧对-右|背拍-左后|背拍-右后`
    （只有 `正面` 和 `反打` 可以不带方位）
11. 同一场戏内，连续镜头的机位必须在 180° 轴线的**同一侧**
12. 距离写数字，单位米，范围 0.4–8
13. **每个镜头都必须写运镜值**，不允许留空
14. **固定机位不得超过全片镜数的 1/3**，且**不许连续 3 镜固定**
15. **运镜必须跟情绪走**，按下面的含义表选，不许随机填：
16. **同一场戏里运镜方向要连贯**：推完不要立刻拉；横移方向不要来回翻

### 运镜含义表（第 15 条的判据）

| 运镜 | 观众感受 | 什么时候用 |
|---|---|---|
| **固定** | 冷静、旁观、凝固 | 情绪停顿、对峙的最后一秒、尸体/空景 |
| **缓推** | 靠近内心、压迫、聚焦 | 人物下定决心的瞬间、意识到某事的瞬间 |
| **缓拉** | 疏离、揭示、变渺小 | 说完重话之后、人走开、露出环境 |
| **横移** | 跟随、展示空间关系 | 走进房间、扫过一排物件、两人之间的空间 |
| **跟拍** | 代入、紧张 | 走路、追逐、逃 |
| **手持** | 不安、真实、临场 | 争吵、推搡、慌乱 |

**用法**：每一场至少出现 3 种不同运镜；同一镜头内只允许一种运镜。

> 为什么运镜能解决"干巴"：固定的画面里，观众只能看人物的微表情；
> 一旦镜头在动，**画面本身就在产生信息**（空间被揭示、距离被改变），
> 5 秒就不会觉得长。

### 空镜（0 人）的额外要求

17. 空镜必须满足：**≥3 个环境动态** + **1 个"回应"事件**（水花溅回、锅盖被汽顶起、帘子被风带起又落）
18. 空镜不许连续出现 2 个（中间必须有人物镜）

## D. 人物（6 条）

19. 每镜出场角色 **1–3 人**（0 人只能是空镜，且必须无台词）
20. 六要素齐全：`位置 / 层级 / 朝向 / 视线 / 占比`（`对象` 在视线=看对方时必填）
21. `视线=看对方` 时，`对象` 必须是**本镜出场角色**之一
22. `占比` 范围 20–80
23. 两人同框时，两人的 `朝向` 必须**镜像相反**（一个 左3-4侧，另一个 右3-4侧）
24. ≥2 **人**必须有 `【关系】`；单人镜不写。人和动物同框时不强制，但建议写（见下）
25. 人和动物同框，关系值用这 6 个之一：`蹲在脚边 / 伏在膝前 / 跟在身后 / 扑向人 / 抱在怀里 / 隔在两人之间`

## E. 台词（7 条）

25. 格式：`<d>说话人：台词</d>`；对某人说写 `<d>说话人→对象：台词</d>`
26. 有台词就必须有 `【语气】`，值只能是：`压低 / 急促 / 发颤 / 冷笑 / 咬牙 / 轻描淡写 / 柔和 / 气声 / 平静 / 压抑 / 失控`
27. 同一场戏里，两个角色的 `【语气】` 不能相同
28. 一句台词必须在一镜内说完，不许跨镜
29. **台词字数下限**：5 秒 ≥9 字 · 8 秒 ≥15 字 · 10 秒 ≥22 字
    （低于下限就是"几个字占一整个镜头"，会空；处理办法见下）
30. 台词说完后：要么在 1 秒内切镜，要么留 **≥2 个反应节拍**
31. 一句台词不许拆成两镜（上句在下镜开头继续说 = 禁止）

> **短句怎么办**（第 29 条的三个解法，任选）：
> ① 把**同一人**的下一句并到这一镜
> ② `【开口】` 调晚，前半用动作建立
> ③ 改成**画外音**：这一镜拍听的人/背影/环境，声音从画外进来

## F. 对话镜头 · 正反打（4 条）

32. **禁止**：≥2 人 + `特写/近景` + 有台词（必须拆成正反打）
33. 每场对白必须在开头有一个**建立镜**（中全/全景，两人都入画，都不说话）
34. 3 人场：说话人切**单人镜**；其余人用**过肩镜**（机位在其后方，只露后脑/肩，虚化）
35. 正反打两镜的景别、高度、距离必须**基本一致**

## G. 节奏与反应（10 条）

36. 节拍数量：5 秒 ≥3 拍 · 8 秒 4–5 拍 · 10 秒 5–6 拍
37. 每一拍都必须包含**身体部位**或**环境物体**
38. 每镜 ≥2 个**微表情**，且来自**不同部位**
39. 每镜 ≥1 个呼吸或衣料细节（胸口起伏/袖口被带起/衣摆掀动）
40. 每镜 ≥2 个环境动态（灯笼晃/火苗跳/烟斜飘/浮尘翻/帘动）
41. 每镜 `【场景】` 必须写出**前景遮挡物**（虚化）
42. 最后一拍时间 < 时长，且至少留 0.4 秒余势
43. **每镜必须有"反应"——不允许出现"没人被影响、没有回应"的镜头**

### 第 43 条：什么叫"有反应"

| 镜型 | 必须有 | 举例 |
|---|---|---|
| **有台词、有人听** | 听的人的反应 | 瞳孔一缩、呼吸停半拍、手指停下、视线滑开 |
| **有台词、无人听** | 说话者说完后的余波 | 说完抿嘴、喉结滚动、肩膀落下、手松开 |
| **无台词、有人** | 这个人对**画面外某事**的反应 | 侧耳听、看向门外、被汽烫得缩手、脚趾抠地 |
| **空镜（0 人）** | 物件对动作的**回应** | 水花溅回、锅盖被汽顶起、帘子被风带起又落、狗甩水时水雾炸开 |

**判定方法（写完后自问）**：

```
把这一镜放完，观众心里有没有产生"所以我看到了什么"？
  有  → 通过
  没有 → 这一镜是空的，合并到相邻镜，或加一个反应节拍
```

44. 连续 3 镜不许都是"低信息镜"（纯流程动作：穿鞋、端盆、开门、走路）
45. 60 秒的集，台词总字数 ≥ 60 字；无台词镜 ≤ 全片镜数的 30%

## H. 声音与转场（3 条）

46. 音效 ≥2 层：环境底噪 + 本镜动作声
47. 配乐只写 `乐器 + 速度 + 节奏`，**禁止情绪词**（悲伤/紧张/温暖…）
48. 转场只有 `cut` 或 `chain`；`chain` 只用于同一批人连续动作

## I. 场景（3 条）

49. 场景卡必须包含：`id`、`机位`、`固定物件`、`光源（方位+色温）`、`母版镜头号`
50. 镜头表 `场景` 列只能写**场景卡的名字或 id**，不许自创
51. 同一场景的所有镜头，光源方位必须一致

## J. 资产（2 条）

52. 角色定妆照：每人 3 张（正/侧3-4/背），**同一套衣服**；场景母版：每场景 2 张，**同一时刻**
53. 场景母版必须 **1344×768**、画面无人、三个距离层、≥2 个可动元素、光源方位写死
54. 有台词的镜头，**【节奏】里不许再写「开口说 / 开口喊 / 嘟囔 / 说道」**。
    台词的时间点只由【开口】给出；节奏里重复下「开口」指令 = 模型收到两个发声信号，
    开头会多一个含糊的音节（听着像「诶」），台词还会被推后或重复。
    写法：`✗ 2.0 开口嘟囔、下巴搁在膝盖上` → `✓ 2.0 下巴搁在膝盖上、嘴抿了一下`
    校验码 `SPEECH_CUE_DUPLICATE`；编译器渲染时也会自动剥掉这类片段（双保险）。
55. 参考图一共 **9 个槽**（人物图 + 场景图**共享**，H3 节点硬上限）。三人同框时每人 2 张才给场景和末帧留得出位置；
    每人 3 张 = 9 会把场景图整张挤掉，模型就开始自己编房间。
    槽位由 `studio/core/refs.py` 的预算器统一分配（末帧 > 场景主图 > 每人 1 张 > 补充视角），
    结果落库在 `shots.ref_plan_json` 并参与指纹；渲染器只消费计划，不再自己 `refs[:4]`。
    校验码：`REF_SLOTS_DROPPED`（有图被丢）、`REF_SLOTS_FULL`（刚好用满，会变慢）。

## 附：模型选择（实测，2026-11-19）

同一镜（三人吃饭，9 槽用满，机位=中全/平视/正面/固定 8 秒）用两套权重各渲一次：

| 权重 | 首尾帧差 | 观察 |
|---|---|---|
| **fl2va（默认）** | **0.140** | 有运镜、构图正常 |
| ref2va（参考图优先） | 0.018 | 几乎不动、构图更平，前景被塞了一只大碗 |

**结论：默认 fl2va。** ref2va 在本机实测不跟随运镜，暂不作默认；
只在"机位固定、身份最关键"的镜头上再单独验证是否值得切换（切换一次要重载 19.5 GiB，1–3 分钟）。

## 附：运镜合法值（以 `scripts/shot_grammar.py` 为准）

```
固定 / 缓推 / 缓拉 / 横移 / 跟拍 / 手持 / 环绕-左 / 环绕-右
```

`环绕-左` `环绕-右` 是后加的：语义是"相机沿弧线绕主体转到一侧，约 30°"。
**实测上限就是 30° 左右**——想拍 270° 环绕必须靠 4 镜拼接（高度/角度递进 + 在运动里切），
单镜做不到（模型没有三维场景表示）。

57. 台词先写成人话，再数字数。**字数不够就补动作，不许补废话。**
    常见毛病：为了凑 5 s 的 9 字、8 s 的 15 字，往里塞「锅里还有」「我今天也不吃了」「你吃吧」这类从句——
    听起来就不是人会说的话。

```
✗ 我不爱吃这个，你吃吧，锅里还有。      ← 肉是刚买的，锅里根本没有
✓ 我不爱吃这个，你吃吧。

✗ 妈不吃，我今天也不吃了，你吃。        ← 「我今天也」是为了凑字数
✓ 妈不吃，我也不吃。

✗ 那我今晚就睡，明天你叫我。            ← 「就睡」不通，谁晚上不睡
✓ 那我今晚早点睡，明天你叫我。
```

**写完自查三问**：
1. 这句话，生活里有人会这么说吗？（不通就重写，不是加字）
2. 删掉后半句，人物会显得不够善良吗？（不会 → 删）
3. 台词短了，能不能用「手停一下」「咽口水」「低头笑」这类动作补？

时长不够是**镜头的问题**，不是**台词的问题**：补拍、补反应、补道具动作，不要补话。

58. 【节奏】只写看得见的动作；**声音写进【音效】**。
    实测：s01 的节奏里写了「院子里只有鸡应了一声、他把声音咽回去」，渲出来模型把这句话**当旁白念了出来**。

```
✗ 3.6 声音比平时低、喊了一声
✓ 3.6 他抬起头、嘴张开、下巴往前送、眼睛睁着          （声音交给【音效】）

✗ 0.0 院外传来收破烂的吆喝、由远到近
✓ 0.0 窗纸上晃过一辆推车的影子、由远到近                （先给画面，声音另外写）

✗ 3.2 蒜末下锅、刺啦一声、她往后仰
✓ 3.2 蒜末下锅、锅口腾起一股白烟、她往后仰
```

禁用词（会被当台词）：应了一声 / 响了一声 / 叫了一声 / 喊了一声 / 传来 / 听见 / 声音 / 一声。
校验码 `BEAT_SOUND` 会自动查这些词。

59. **道具一旦出现，必须交代去向**，否则模型会把它抹掉。
    实测：s01 他穿着红凉鞋睡、掀被子后鞋直接消失——因为提示词里既说「服装锁：红凉鞋」又说「光脚伸到炕沿外」，模型先画了鞋，再让鞋消失来满足「光脚」。

```
✗ 服装锁：红色塑料凉鞋                 （等于睡觉也穿着）
✓ 服装锁：红凉鞋（出屋时穿）；在炕上赤脚

✗ 8.4 光脚伸到炕沿外                  （鞋凭空没了）
✓ 0.0 两只红凉鞋并排摆在炕沿下的泥地上（入画）
✓ 8.4 他光脚伸到炕沿外、脚趾碰到凉鞋的鞋面（鞋还在）
```

通用写法：**出现 → 移动 → 落点**。拿起来就写放回哪，扔出去就写落在哪。

# 2D 动画变体（换词表，其余规则不变）

> 正反打、轴线、节拍、语气、时长、运镜这些**全部照用**——它们管的是构图和信息量，与画风无关。
> 需要换的只有"画质描述"和"微表情语汇"。

## 改这四处

| 位置 | 真人版 | 2D 动画版 |
|---|---|---|
| `## 世界设定` 视觉语言 | `35mm film grain, shallow depth of field` | `2D anime, cel-shaded, clean line art, limited palette, hand-drawn background` |
| `【画质】` | `35mm 胶片质感，浅景深，真实皮肤纹理` | `赛璐璐上色，线稿干净，平涂阴影，背景手绘，2D 动画` |
| 微表情清单 | 皮肤纹理、汗光、毛孔 | 瞳孔高光、眼睑阴影、眉毛角度、口型张合、发丝飘动 |
| 参考图 | 写实定妆照 | **必须是 2D 动画立绘**（写实图会渲成 3D 动画脸） |

## 2D 专用的微表情清单（替换第 38 条的部位清单）

```
眼：瞳孔放大缩小、高光亮起/熄灭、眼睑下垂、眼尾阴影加深
眉：眉梢挑起、眉心挤成竖线、眉毛整条上抬
口：口型从闭到半张、嘴角一侧上提、下唇被牙咬住
发：发丝被风吹起、刘海遮住眼睛、马尾甩动
体：肩线塌下去、身体前倾一寸、手指收紧
```

## 2D 的运镜注意

```
2D 动画的"缓推"要用 缩放背景层 + 前景层视差，不能只推一层
横移时前后景速度必须不同（近快远慢），否则看起来像一张图在平移
```

## 2D 的额外禁止项

```
❌ 出现"皮肤纹理、毛孔、汗珠、油光"（会渲成 3D 动画）
❌ 出现"真实材质、电影感、浅景深"（2D 动画不需要景深）
❌ 参考图里混写实照片与 2D 立绘（模型会把两者平均成诡异画风）
❌ 一镜里出现"线条粗细不一/上色风格切换"（2D 最怕这个，只能靠参考图锁死）
```

## 2D 的上手顺序（重要）

```
1. 先渲 1 个单人 5 秒空镜（只有场景母版）→ 确认画风对不对
2. 再渲 1 个单人近景（1 张角色 2D 立绘）→ 确认脸有没有崩
3. 都过了，再按正反打排一整场
```

**不要一次排 10 镜**：2D 风格在视频模型里比写实更不稳定，先用两镜验证画风，
否则 10 镜渲完发现线条抖，全部白渲。

## 56. 15 秒长镜（2026-11-19 起可用）

H3 的帧数网格是 `17k+5`，15 秒 = **362 帧（15.083 s）**，与 5/8/10 秒同一套网格。
**用途**：把一段连续动作装进一镜（醒来→找→落空、淘米→生火、让肉的正反打之后的「喂进去→两人笑」）。

```
8 s   最少 4 拍   台词 15–27 字
10 s  最少 5 拍   台词 20–34 字
15 s  最少 7 拍   台词 30–52 字（无台词镜 ≥8 拍）
```

**「空」的根源不是时长，是每拍之间没有可见动作。** 15 秒镜必须有 7 个可拍的动作/反应。
