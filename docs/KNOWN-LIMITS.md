# 已知限制

这些不是"待办"，是**已经实测出来的边界**。写在这里是为了让你少走弯路，也为了不让这个项目假装能做到它做不到的事。

---

## 一、模型能力边界

### 1. 单镜只有 5 秒

`124 帧 @ 24 fps = 5.167 秒`。一镜超过一个动作，模型只会渲首尾两态，中间靠插值，看起来像"跳了一下"。

**对策**：一镜一动作；长动作拆成多镜。

### 2. chain 会锁死画面（最坑的一条）

`chain` 的语义是"把上一镜末帧逐像素作为本镜首帧"。锁得越死，模型越不敢动。

实测（8 镜短片，全部 chain）：

```
镜号  内部运动(首↔末)   与前一镜首帧
s05   0.981            0.987
s06   0.981            0.989
s07   0.983            0.988
s08   0.971            0.966
```

> 0.98 意味着这一镜 5 秒内几乎没变。整片看下来就是同一个画面在拖。

**对策**：换人 / 换机位 / 大动作 → 用 `cut`。界面「按角色自动设转场」会自动判断。
实测把 s07/s08 从 chain 改成 cut 后，内部运动从 0.87/0.94 降到 0.45/0.39，画面开始动了。

### 3. 快速动作渲不出来

"枪托砸脸""匕首由下至上刺入"这类动作，模型会退化成"举着枪对峙"。
它擅长的是**姿态变化 + 镜头运动**，不擅长**快速接触动作**。

**对策**：把"砸"拆成"抬手 → 挥下"两镜；或用声音/剪辑暗示。

### 4. 角色一致性有限

- 1 张参考图：脸会漂，时胖时瘦
- 2–3 张（正面 + 3/4 侧 + 侧后）：明显改善，但仍非 100%
- 参考图之间必须是**同一个人、同一套衣服、同一光线**，否则模型学混

### 5. ≤3 角色/镜

`H3CastMember` 的硬上限。第 4 个角色会被静默跳过（日志里有 WARNING，界面不提示）。

### 6. 不产音频

H3 只出画。台词字幕是后期烧上去的，没有配音。要声音得另接 TTS。

## 二、硬件边界

| 项 | 实测 |
|---|---|
| 1344×768 / 20 步 | 432–487 秒/镜，峰值 **22.5–24.1 GB** |
| 840×480 / 12 步（草稿） | 116.5 秒 |
| OOM | 24 GB 卡在 1344×768 **偶发**；执行器会 `/free` 释放显存后重试一次，仍失败则该镜标记失败 |
| 16 GB 卡 | 建议 896×512 / 16 步，或用 int8 VAE |
| 12 GB 卡 | 未验证，预计只能 512×288 且极慢 |

## 三、工程边界

| 限制 | 说明 |
|---|---|
| 单机单卡 | 队列一次只跑一个任务；多卡需要改认领逻辑 |
| 无鉴权 | 只监听 127.0.0.1，不要直接暴露公网 |
| 无多用户 | 一个数据库一个使用者；没有权限模型 |
| Windows 原生 | 不支持。当前整套跑在 WSL2 |
| 模型不随仓库分发 | 许可未确认，安装器只做检测，不下载 |
| 备份是"够用"级 | 每日 SQLite backup + rsync，不是高可用方案 |

## 四、画质：目前到什么程度

用《兵王·劫机》8 镜实测，客观指标全过、主观仍有硬伤：

| 维度 | 状态 |
|---|---|
| 画面在动、八镜各不相同 | ✅ 内部运动 0.31–0.54，相邻镜首帧 0.30–0.41 |
| 字幕 | ✅ 但位置偏低、偶有遮挡 |
| 角色一致性 | ⚠️ 叶谦时胖时瘦（3 张参考图），另两人各 1 张更飘 |
| 动作实现 | ⚠️ "枪托砸脸""匕首反杀"退化成对峙 |
| 空间连续 | ⚠️ 同一舱内座位朝向在几镜里不一致 |
| 音频 | ❌ 只有字幕，没有配音 |

**结论：能讲清故事，还不是能卖的成片。** 谁要说这个项目直接出片了，可以把这张表甩给他。

## 五、我们踩过、已经修掉的坑

留在这里当"别人也会踩"的清单：

| 坑 | 症状 | 修法 |
|---|---|---|
| 指纹算法加字段 | 所有历史 take 突然"失效" | 可选字段只在被使用时进哈希 |
| 执行器每镜独立目录 | chain 找不到上游 → 每镜都从母版起步 | 渲染前把上游片段复制进工作目录 |
| 复制品被当成产物 | 下一镜的 take 实际是上一镜的复制 | 产物只认当前镜号文件，明确排除复制品 |
| 预览任务改状态 | 点预览 → 显示"生成中" → 又变回"未生成" | preview 与 render 分离，preview 不改状态 |
| 两个服务进程抢队列 | 后几镜 3 秒内连续失败 | 原子认领 + 启动清理遗留 running |
| OOM 后模型半死 | 重试也失败 | `/free` 卸载模型 + 重试一次 |
| 计划用筛选后的列表找上游 | 单渲 chain 镜永远报"是第一镜" | 按全片顺序找上游 |
| 角色图缓存 | 换图后界面还是旧图 | 资源 URL 带版本参数 |
