# 部署完整性：一个会用的开发者能不能独立装出来？

写这份文档的原因是：**"代码开源"不等于"别人能跑"**。
下面把整条链路拆成 12 项，逐项标注"能不能自动""拿不到会怎样"。

---

## 一、逐项判定

| # | 组成 | 谁提供 | 能否自动 | 拿不到的后果 |
|---|---|---|---|---|
| 1 | Python 3.10+ | 开发者 | ✅ 脚本检测 | 直接退出 |
| 2 | FFmpeg 5+ | 包管理器 | ⚠️ 需手动 `apt install ffmpeg` | 合并/烧字幕失败 |
| 3 | NVIDIA 驱动 + CUDA | 开发者 | ❌ 系统级，不代劳 | `ov doctor` 报 gpu 失败 |
| 4 | ComfyUI 0.30.0 | `git clone` | ✅ 自动 | — |
| 5 | ComfyUI 的 pip 依赖（torch/transformers） | pip | ✅ 自动（5–15 分钟，2–5 GB） | 引擎起不来 |
| 6 | 本项目的 Python 依赖（6 个包） | pip | ✅ 自动（约 1 分钟） | — |
| 7 | **6 个 H3 权重（57 GB）** | **开发者** | ❌ **无公开来源** | **完全不能渲染** |
| 8 | `H3CastMember` 节点 | 权重包附带 | ❌ 私有 | 角色一致性不可用（纯文生视频仍可） |
| 9 | 模型目录挂载（不在 ComfyUI/models 时） | 安装器 | ✅ 自动写 `extra_model_paths.yaml` | 引擎找不到权重 |
| 10 | 服务注册（systemd 或 ov start） | 安装器 | ✅ 自动 / 半自动 | 起不来 |
| 11 | 数据目录与数据库 | 代码 | ✅ 启动时自动建 | — |
| 12 | 一次真实渲染验证 | 开发者 | ✅ `ov selftest` + 示例剧本 | 不知道装没装对 |

---

## 二、结论（直说）

### ✅ 能独立完成的

一个会用的开发者，**只要手上有那 6 个权重文件**，可以完全按文档装起来：

```
git clone → bash install.sh --models-dir … --comfyui-dir …
→ ov start → 打开 8801 → 导入示例 → 计划 → 确认 → 出片
```

这条路径**我们在陌生目录 + 全新 HOME + 全新 venv 下实测过**：装依赖 → 起服务 → 真实渲出 5 秒 832×480 片段（108.8 秒）。

### ❌ 卡死的地方

**权重没有公开来源。** 这是硬阻塞，不是配置问题：

- `manifest/models.json` 里 `sources` 是空的
- 文档只能写"从你获得授权的渠道获取"
- 57 GB 的 int8 量化权重，没有一句可执行的下载命令

所以现状是：**能装框架，不能凭空造出模型。** 谁拿到权重谁能跑，拿不到就是 `ov doctor` 报 `models` 失败后停住。

### ⚠️ 只有"部分能力"的降级路径

不装 `H3CastMember` 节点时：

| 能力 | 是否可用 |
|---|---|
| 纯文生视频（t2v） | ✅ 用 ComfyUI 内置节点，实测可出片 |
| 首尾帧 / 链式接续 | ✅ |
| **角色参考图（一致性）** | ❌ 工作流里会多出 `H3CastMember`，引擎拒绝整条 prompt |

**这意味着**：没有私有节点，你只能做"空镜/风景"这类片子，做不了"同一个人演 8 镜"。

---

## 三、给上传开源平台的两个选择

### 选择 A：按现状发布（推荐）

- README 首屏就写：**BYO weights（自备权重），本仓库不含模型**
- 明确"能跑通框架 + 有实测数据"，但**不承诺开箱即用**
- 好处：不背锅，issue 会少；坏处：star 会少（很多人就是要一键）

### 选择 B：补上权重来源

- 查清 H3 权重许可，若允许再分发 → 加 `ov fetch-models`（M2，约 2 天）
- 若不允许 → 只能写"如何从官方渠道获取"的分步指引 + 校验脚本
- 好处：真正可用；坏处：许可风险 + 57 GB 的下载支持成本

> 我的建议：**先按 A 发，把 `docs/KNOWN-LIMITS.md` 和这份文档一起放上去。**
> 能跑的人自然会跑；跑不了的人至少知道卡在哪，而不是来问"为什么 clone 完打不开"。

## 四、开发者实际执行清单（照抄可用）

```bash
# 0. 前置：驱动 + ffmpeg
nvidia-smi && ffmpeg -version

# 1. 克隆
git clone <repo> openvideo && cd openvideo

# 2. 自备权重后，指向它们
bash install.sh --models-dir /data/h3-models

# 3. 体检（应显示"可用"或只剩 nodes 缺口）
./ov doctor --models-dir /data/h3-models

# 4. 启动（无 systemd 环境也能用）
./ov start

# 5. 验证
./ov selftest          # 两个端口都该 200
# 浏览器打开 http://127.0.0.1:8801 → 导入 examples/hijack_8.md

# 6. 停
./ov stop
```

预计耗时：

| 步骤 | 时间 |
|---|---|
| 装 ComfyUI 依赖（含 torch） | 5–15 分钟 |
| 装本项目依赖 | 1 分钟 |
| 引擎首次加载权重 | 1–2 分钟 |
| 一条 5 秒草稿镜头 | 约 110 秒 |
| **合计（有权重的前提下）** | **约 20–30 分钟** |
